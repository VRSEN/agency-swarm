We welcome contributions to Agency Swarm! By contributing, you help improve the framework for everyone. Here's how you can get involved:

## Setting Up Your Development Environment

You need Python 3.12 or later, Git and [uv](https://docs.astral.sh/uv/).

```bash
git clone https://github.com/VRSEN/agency-swarm.git
cd agency-swarm
make sync                    # creates .venv and installs the dependencies
uv run pre-commit install    # runs the formatters on each commit
```

## Running the Checks

```bash
make format     # ruff format and autofix
make check      # ruff and mypy
make tests      # the test suite
make coverage   # the test suite with coverage; fails below 90%
```

<Note>
  The integration tests call OpenAI and need `OPENAI_API_KEY` in your environment. The unit tests run without a key: `uv run pytest tests/test_*_modules`.
</Note>

## Submitting Changes

1. Create a branch from `main`.
2. Write the change. A change to existing behavior comes with a test that fails without it.
3. Run the checks above.
4. Update the docs when behavior that users see changes.
5. Open a pull request and fill in the template: what changed, why, and how you tested it.

The full guide, including the SDK upgrade and release procedures, is in [CONTRIBUTING.md](https://github.com/VRSEN/agency-swarm/blob/main/CONTRIBUTING.md).
